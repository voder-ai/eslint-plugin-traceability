# Branch Annotation Requirements Inside Anonymous Arrow Functions

## Context

Anonymous arrow functions are excluded from function-level annotation requirements by default, but the code branches inside those arrows still represent meaningful control flow. The branch annotation rule should enforce `@story`/`@req` (or `@supports`) on those branches just like it does at the top level.

## Requirement

**REQ-ARROW-FUNCTION-BRANCH-INCLUDED** — Branch nodes inside anonymous arrow functions MUST be treated the same as top-level branches for annotation requirements.

This requirement is about branch annotations only. It does **not** change the function-level exclusion for anonymous arrows.

## Specification

1. The `require-branch-annotation` rule MUST report missing annotations on branch nodes even when those branches are nested inside anonymous arrow functions.
2. The rule MUST accept valid branch annotations inside anonymous arrows the same way it does for top-level branches.
3. The rule MUST apply the same auto-fix placement rules inside anonymous arrows as it does elsewhere (inside-placement by default, or before-branch when configured).

## Examples

### Invalid: Missing annotation inside anonymous arrow

```javascript
items.map(() => {
  if (ready) {
    doWork();
  }
});
```

### Valid: Annotated branch inside anonymous arrow

```javascript
items.map(() => {
  if (ready) {
    // @story docs/stories/004.0-DEV-BRANCH-ANNOTATIONS.story.md
    // @req REQ-BRANCH-DETECTION
    doWork();
  }
});
```
