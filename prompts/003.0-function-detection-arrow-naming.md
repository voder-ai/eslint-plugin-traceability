# Arrow Function Detection and Naming Resolution

## Context

This specification defines how the ESLint plugin detects and classifies arrow functions for traceability annotation requirements, particularly distinguishing between anonymous and named arrow functions.

## Problem

Arrow functions in JavaScript/TypeScript have unique characteristics:

- They never have their own `id` property (unlike regular function declarations)
- Their "name" comes from their context (variable assignment, object property, etc.)
- Anonymous arrows are commonly used as utility callbacks (map, filter, setTimeout, etc.)
- Named arrows represent meaningful functionality and should require annotations

The plugin must correctly distinguish between these cases to enforce appropriate annotation requirements.

## Specification

### 1. Anonymous Arrow Function Detection

**Anonymous arrow functions** are arrows with no assigned name. They are excluded by default from annotation requirements (REQ-FUNCTION-DETECTION#1).

**Detection logic:**

```typescript
function isAnonymousArrowFunction(node) {
  if (node.type !== "ArrowFunctionExpression") return false;

  // Check parent for name assignment
  const name = getNameFromParent(node.parent);
  return !isValidName(name);
}

function requiresOwnFunctionAnnotation(node, options) {
  // Test framework callbacks are excluded (when excludeTestCallbacks is true)
  if (isTestFrameworkCallback(node, options)) {
    return false;
  }

  // Nested anonymous functions may inherit from parent
  if (isNestedFunction(node) && isEffectivelyAnonymousFunction(node)) {
    return false;
  }

  // Anonymous arrows are excluded by default (REQ-FUNCTION-DETECTION#1)
  if (isAnonymousArrowFunction(node)) {
    // Special cases where anonymous arrows ARE checked:
    // - When excludeTestCallbacks is explicitly false
    // - Vitest bench() callbacks
    if (options?.excludeTestCallbacks === false) {
      return true;
    }
    if (isBenchCallback(node)) {
      return true;
    }

    // All other anonymous arrows are excluded by default
    return false;
  }

  return true;
}
```

### 2. Named Arrow Function Detection

**Named arrow functions** are arrows assigned to identifiers:

- Variable declarations: `const handler = () => {}`
- Object properties: `{ handler: () => {} }`
- Class properties: `class Foo { handler = () => {} }`

**These always require annotations**, even when:

- Nested inside other functions
- Used as callbacks
- Defined in test files

Names are resolved by inspecting the immediate parent node (VariableDeclarator or Property).

**Detection logic:**

```typescript
function isNamedArrow(node) {
  if (node.type !== "ArrowFunctionExpression") return false;

  // Check parent VariableDeclarator
  if (node.parent.type === "VariableDeclarator" && node.parent.id) {
    return isValidName(getIdentifierName(node.parent.id));
  }

  // Check parent Property (object or class)
  if (node.parent.type === "Property" && node.parent.key) {
    return isValidName(getIdentifierName(node.parent.key));
  }

  return false;
}

// In practice, we check if anonymous first
// If isAnonymousArrowFunction returns false, it's a named arrow
```

### 3. Name Validation

A name is considered valid if it:

- Is a non-null string
- Has length > 0
- Is not the literal string `"(anonymous)"`

```typescript
function isValidName(name: string | null): boolean {
  return typeof name === "string" && name.length > 0 && name !== "(anonymous)";
}
```

### 4. Parent Context Inspection

Arrow functions require inspecting parent nodes to resolve names. The implementation checks the immediate parent (VariableDeclarator or Property) to determine if an arrow function is named.

```typescript
function getNameFromVariableDeclarator(parent) {
  if (parent.type === "VariableDeclarator" && parent.id) {
    return (
      getContainerKeyOrIdName(parent) ?? getDirectIdentifierName(parent.id)
    );
  }
  return null;
}

function getNameFromProperty(parent) {
  if (parent.type === "Property" && parent.key) {
    return (
      getContainerKeyOrIdName(parent) ?? getDirectIdentifierName(parent.key)
    );
  }
  return null;
}

// Used by isAnonymousArrowFunction
const name =
  getNameFromVariableDeclarator(node.parent) ??
  getNameFromProperty(node.parent);
```

### 5. Callback Exclusion Logic

The complete logic for determining which functions require annotations:

1. **Test framework callbacks** (when `excludeTestCallbacks` is true): Excluded
2. **Nested anonymous functions**: Excluded (may inherit from parent)
3. **Anonymous arrow functions**: **Excluded by default** (REQ-FUNCTION-DETECTION#1)
4. **Named arrows** (all contexts): **Checked**
5. **Named nested functions**: **Checked**

Special cases where anonymous arrows ARE checked:

- When `excludeTestCallbacks` is explicitly `false` (all functions checked)
- Vitest `bench()` callbacks (always checked for performance traceability)

This ensures that:

- Anonymous arrow callbacks don't clutter code with annotations
- Named functions always carry explicit annotations
- Nested anonymous functions can inherit parent annotations
- Performance benchmarks maintain traceability even with anonymous callbacks

## Examples

### Anonymous Arrows (Excluded by Default)

```javascript
// Array method callback - excluded
const nums = [1, 2, 3].map(() => Math.random());

// Promise callback - excluded
fetch(url).then(() => console.log("done"));

// Timing callback - excluded
setTimeout(() => refresh(), 1000);

// Custom function callback - excluded (REQ-FUNCTION-DETECTION#1)
customWrapper(() => {
  // No annotation required
});

// Nested anonymous - excluded (inherits from parent)
/** @story docs/stories/example.story.md */
function process() {
  items.forEach(() => {
    // No annotation required
  });
}
```

### Named Arrows (Required)

```javascript
// Variable assignment - REQUIRES annotation
/** @story docs/stories/example.story.md */
const handler = () => {
  // implementation
};

// Object property - REQUIRES annotation
const obj = {
  /** @story docs/stories/example.story.md */
  handler: () => {
    // implementation
  },
};

// Named nested arrow - REQUIRES annotation
/** @story docs/stories/example.story.md */
function outer() {
  /** @story docs/stories/example.story.md */
  const inner = () => {
    // implementation
  };
}
```
